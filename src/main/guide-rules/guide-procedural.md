
# Procedural and Quantitative

For accounting, tax calculations, statistics, finance and similar courses. These courses mostly ask students to run a procedure with several dependent steps, where an early mistake changes the answer. That's exactly where worked examples, fading and step layouts earn their space.

Follow guide-core for ground rules, exam matching, item writing and how the page looks: plain text by default, boxes only for the content guide-core section 7 lists. This file sets what the notes and practice contain.

## Why

- Worked examples have a medium effect in math learning (g about 0.48 across 55 studies; Barbieri et al. 2023), whether used for first learning or practice. Correct examples work better than error examples.
- Example then problem beats problem then example (van Gog, Kester and Paas 2011).
- Fading steps and moving to independent problems as skill grows is standard (Renkl and Atkinson; expertise reversal).
- Self-explanation prompts on top of worked examples are mixed evidence (Barbieri et al. 2023; Bisra et al. 2018), so the reason for each line is given beside it rather than asked for.
- Practice transfers when it uses genuinely new problems, not the same example again (Pan and Rickard 2018).
- Mixing look-alike problem types helps a little in math (g about 0.34; Brunmair and Richter 2019).

## Notes

- **Rules and formulas** go in a KEY box: the formula or rule itself and its source as the course cites it. What it measures, how to read the result, and when it applies are plain text around the box.
- **Concepts** that aren't a formula or rule (what an account is for, why a treatment exists) are plain text.
- **Layouts** in the course's own format first. Otherwise:
  - Accounting: journal entries as a table (Date | Account titles and explanation | Debit | Credit | Why), credits indented, blank row between entries. T-accounts with debits left, credits right. Schedules and statements with a centered three-line heading (entity, statement, date or period), amounts right-aligned with commas, $ on the first amount and on totals, single rule above subtotals, double rule under the final total, deductions in parentheses.
  - Tax: the computation in the course's order, each line with its section or rule beside it.
  - Math and stats: formula, then values substituted, then the result with units, each on its own line.
- The reason or rule for each line sits beside it (a Why column).
- Rates, limits and thresholds only from the materials (guide-core ground rule 3).

## Practice

- **Worked example A** (EXAMPLE box): fully worked, grouped under step labels, reason beside each line. When the slides or solutions manual already work an example of that procedure, that example is Example A, laid out in this format with the course's own numbers. Don't retell it in a paragraph and then add a separate invented Example A; each procedure is fully worked once. Invent Example A only when the materials have no worked example for that procedure.
- **Example B** (TRY IT box, right after A): same type and layout, new numbers, the last one or two steps left as blanks with no hints. Answers collapsed right after it.
- Always example first, then problem. Never a problem before its example.
- **Practice problems** (TRY IT box after the week quiz): full problems with new numbers and situations, at exam difficulty, mixed across the week's look-alike problem types. The student works them on paper, so give the step labels but no empty tables. Answers collapsed right after the box, with full working.
- **Concept checks** (which treatment applies, what a ratio means) go in the week quiz when the exam has multiple choice. Wrong options come from common slips: wrong rate, sign error, missed threshold, wrong order of steps.
- Step tables only for real multi-step work. A one-number lookup gets one line of text.

## In a learning guide

- Each topic: the rule or formula, the explanation in plain text, the layout, then Example A and Example B for each main procedure. When a later topic reuses a procedure already fully worked, start it at Example B.
- Practice problems come after the week quiz, not inside topics.
- Short-on-time mode: Example A plus B for each core procedure.

## In a study guide

- Core notes: rules and formulas in cue-table form.
- Methods and layouts: each procedure shown once in the course's format.
- Worked examples: an A then B pair for the most important problem types.
- Practice: week quizzes for concept checks, plus full problems at exam difficulty after each week and after the final quiz, mixed across look-alike types.

## Avoid

- Problems before the example that teaches them.
- Question prompts on individual steps.
- Practice that re-solves the worked example with the same numbers.
- Walking through the slide's worked example in prose and then working a second, invented example of the same procedure.
- Step tables or boxes for single-step lookups.
